# Android 0.11：每日研究入口、已有分析与真实采集状态

## 已有分析完整呈现

同步当前归档修订对应的关键观点和风险提示，不重新请求模型。摘要和观点均标明为已有AI整理，原文及来源保持独立。阅读页提供绿色观点块与浅金色风险块，先展示前三条，可展开其余条目，并加入章节目录。修订号不一致的分析不导出，手机也再次检查修订一致性。

源文件附件和正文不足采用确定性呈现规则。只含文件占位符、图片或附件标题的资料使用紧凑附件卡片，显示真实文件数量和类型；原始标题保留，必要时另外给出可读展示标题。短文不自动视为无效，也不凭空补正文。图片、音频、PDF和表格的原件获取流程继续使用0.9/0.10协议。

## 每日研究入口

首页使用今日收录、关注未读、继续阅读三个可操作入口。今日收录按Asia/Shanghai的首次入库日期计算，与源站发布日期分开；修改摘要、补齐附件、云端sequence变动不会被当作首次收录。历史协议缺少首次入库日期时，不猜测收录时间。

关注公司的最多两篇未读材料优先呈现，完整列表保留全部资料与来源。公司目录按关注优先、最近研究日期优先排序，显示最近研究日期；名称待匹配对象仍保留。未新增财务或估值推断。首页计数和已读徽标在返回后原位更新，列表快照、筛选与滚动偏移继续保留。

## 采集与同步状态

Mac通过发布凭据向独立`POST /v1/source-health`上报源站状态。只允许名称、状态、时间、调度间隔、待补全数量及受限的故障分类，不上传登录凭据、原始错误消息、签名URL或内部路径。没有研报变化时仍上报，状态更新不推进研报cursor。

手机分别展示源站最近成功采集、Mac最近上报、云端资料更新、手机最近成功检查。点击顶部状态可查看详情；关闭自动采集、部分主题待补全、采集失败、中断、状态未知、超过两分钟没有发布器心跳或源站采集超时均有单独提示。手机网络失败时保留缓存，并明确显示手机同步失败。

自动采集显示配置间隔；失败时另行提示至少15分钟（或更长配置间隔）的退避重试规则。手机刷新只检查云端副本，不代表重新执行源站采集。源站API、登录权限等问题需在Mac信源设置处理；显示状态不等于修复源站错误。旧云端缺少该协议时展示未知状态，不显示虚假的正常结果。

## 部署与兼容

先部署新云端，再重启Mac发布器并回填元数据，最后更新手机。现有授权、TLS、独立容器限制和原文修订哈希规则保持。新版字段有默认值，旧APK仍能读原文；新版缓存会复用同修订正文并结合最新分析、附件元数据。

本轮不新增模型调用、手机权限、后台推送、跨端笔记或结构化财务页。测试覆盖修订隔离、原件卡片规则、状态接口鉴权、无变化时心跳及cursor不变、上海自然日收录、状态失效和真机工作台/分析展开与返回导航。

### 本地目录恢复

手机启动时若目录文件缺失或损坏，会清除目录同步游标并重新从阅读服务下载列表，避免云端版本未变化时一直显示空资料库。收藏、阅读进度和连接凭据保留。正常缓存继续使用增量版本检查。
