# Mac 每日研究工作台

首页增加采集状态条，使用本机既有采集记录，不为页面访问请求知识星球或调用模型。失败、中断、待补和超出常规间隔的成功记录均提示检查；缺少成功时间不能显示一切正常。展开后可看每个信源的最近成功、调度时间、正文待补及分类后的错误原因。关闭自动采集时不声称会自动重试。详情入口指向信源管理。

资料处理统计默认折叠，摘要、附件、待分析仍有各自筛选入口。首页聚焦新收录与原文发表日期；“今日新收录”按首次入库时间统计，修订旧资料不会重复算作新增，与 Android 保持同一口径。旧的“今日导入/更新”统计字段保留，避免改变其他页面含义。

列表卡片隐藏正文开头与标题完全重复的部分，保留正文剩余内容和搜索命中上下文，不改原始资料。首页公司徽标查询覆盖当天与最近两个列表，而非只给最近列表提供关联公司。

统计查询将总数、当天导入、首次入库、当天发表和未知日期合并为一次条件聚合；分组统计仍按原查询实时计算，没有给动态任务状态增加缓存。

本轮只更新 Mac 前端与服务，Android 安装包仍为 0.11.3。
