# Android 0.7.1：从正文返回列表的位置

问题：列表与阅读页共用滚动容器，退出正文时重新生成列表并滚动到顶部，导致读者反复查找刚才的位置。

处理：进入阅读时保留原列表视图和滚动偏移，正文使用独立的临时内容视图。点击顶部返回或系统返回键时，恢复原列表及偏移，不清空行业、公司、来源、时间、关键词或已经加载的页数。重复调整字号和收藏不会覆盖返回位置；PDF 从列表打开时也沿用这条返回路径。加载正文失败时保留当前列表。

返回保留的是当前列表快照，未读列表中刚打开的项目会标为已读但先保留原位置，避免删除一行导致列表跳动。手动同步或主动切换筛选后，再按最新阅读状态生成列表。云端有新资料时，列表更新保留滚动偏移；更新期间行高变化仍可能影响精确位置，不宣称跨更新的逐像素锚定。

此修复处理同一次应用使用中的列表→正文→列表导航；文章内部的持久化阅读进度仍按原有修订保存。没有新增权限、模型调用或云端凭据。

回归测试使用真机列表滚动到非顶部，分别检查顶部返回、系统返回、正文重复渲染后返回、加载页数保留、原视图和偏移恢复。测试临时正文不写入资料库，并恢复临时使用的阅读状态键。
