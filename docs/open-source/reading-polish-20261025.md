# 阅读体验与服务性能优化

Android 0.11.2 将阅读页收藏操作改成原位更新按钮，不销毁和重排正文，也不改变章节、滚动位置和图片任务。返回列表时仍更新收藏标记。真机回归检查内容视图、导航代次和滚动位置均保持不变。

Mac 阅读页增加固定阅读工具、16–24 号正文字体、专注模式、原文 h2/h3 章节目录、阅读进度与继续阅读。字号保存在此浏览器，阅读位置按文档和修订隔离；不跨设备同步。无章节的资料不编造目录。返回列表优先使用站内浏览历史，以保留来源页面和筛选；直接打开文章时回资料库。专注模式可随时退出。

首页及资料库的处理清单复用已解析的归档正文。缓存按绝对路径、修改时间、变更时间和文件大小判断有效性，预算16 MiB（按源文字节的三倍估算），超出预算淘汰旧项。返回元数据副本，避免调用者污染缓存。摘要、模型选择、任务错误和处理状态每次仍重新读取，不缓存旧的分析状态。新归档、原子替换和删除均能及时反映。

本机982份资料的同进程清单测试：首次0.729秒、读归档982次；再次0.095秒、读归档0次，统计一致。这是清单测试，不能代表所有页面或设备都能达到相同提速。

本轮没有新增模型调用、PDF解析或音频转写。
