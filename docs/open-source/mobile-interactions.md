# Android 0.5：行业侧栏与阅读操作

## 导航结构

- 底部只保留动态、公司、原件、收藏四个常用页面。
- 左上角“☰ 行业”打开左侧抽屉，展示真实行业名与资料库总篇数；支持本机关键词搜索与当前行业高亮。
- 选中行业后关闭抽屉并进入对应资料列表，同时清空旧的公司、关键词、时间、来源和阅读状态筛选，避免切换后看不到资料。
- 行业资料页保留当前行业入口，可再次打开侧栏切换；“全部研究”恢复全库动态。
- 关闭按钮、遮罩空白区域与系统返回键均可退出抽屉；打开时默认不弹键盘，点击搜索框后输入。
- 行业页面底部动态入口保持选中；从行业资料列表按系统返回键回到全库动态。

## 阅读交互

返回、收藏、字号和目录固定在阅读页顶部，正文独立滚动。目录定位、阅读比例保存、原文与附件鉴权机制保持原有方式。字号放大及异步图片载入可能导致恢复位置有少量偏差。

## 边界

无新增权限、无第三方追踪、无模型调用；关注、已读、收藏与位置仍保存在本机。侧栏分类数量来自完整资料库，不是当前日期筛选后的数量；界面明确注明这一口径。此版提供按钮打开抽屉，不宣称已支持边缘滑动手势。

验收使用真实小米设备和既有资料：底部四项、侧栏打开/关闭、搜索空结果、行业选中与高亮、恢复全部资料、阅读页滚动时工具栏持续可见、目录跳转及返回列表。
