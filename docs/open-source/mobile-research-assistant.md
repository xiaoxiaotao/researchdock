# 手机 AI 调研（0.13）

安卓顶部“调研”可输入自然语言问题，例如“近30天半导体行业需求有哪些变化和风险？”。公司或行业页会带入当前对象。可指定对象、7/30/90/365天范围，查看任务历史、报告、证据摘录，并继续追问。

## 执行流程

手机通过现有 HTTPS 私有阅读服务提交任务，Mac 的 `app.mobile_sync --watch` 主动领取。Mac 从当前修订的归档正文匹配公司名、证券别名/代码、行业，按日期过滤、正文去重，兼顾高相关材料与检索期间不同阶段的材料，选择相关段落及已有缓存财务报表。DeepSeek 仅收到问题及这些证据，返回中文分节报告。每个实质陈述必须带合法证据编号；无引用的非缺口陈述会省略并显示数量，不会再调用模型补引用；伪造引用编号则拦截整份结果。服务端检验引用编号，手机能点开生成时保存的引句、修订号及当前正文。

没有正文证据时不调用模型；只含 PDF、图像、音频的资料会列入未解析附件数量。不会自动解析附件、转写音频或联网补充行情，也不做估值、目标价或买卖操作。引句准确不代表模型语义判断正确，仍需核对原文。

## 启用（默认关闭）

沿用 Mac 已配置的 DeepSeek Key。在**私有的** `kb-data/catalog/mobile-private.json` 中增加：

```json
{"research_enabled": true, "research_daily_limit": 10}
```

这是需要合并进现有私有配置的两个字段，不是完整配置。保留现有 url、push_token 等连接字段，文件权限应为600。启动/重启 `python -m app.mobile_sync --watch --config <私有配置路径>`。不要把这个文件、密钥、任务快照或报告提交到公共仓库。DeepSeek Key 仅由 Mac 读取；云端和 APK 不存模型 Key。

所有持有当前阅读凭据的设备共享每日任务上限（默认10，配置范围1–30）和最多3个在途任务，不是逐设备权限控制。模型调用还受现有 Mac 每日请求额度约束。网络不确定的模型收据不会自动重发；检查 Mac 收据后再决定重试。重提同一请求编号不重复建任务，同日同问题且证据相同的已完成报告复用，不重复调用模型。最多20段正文摘录、约16000字符，另可加入一份已有财务缓存；输出上限4500 tokens。不会为每篇文章额外调用模型。

Mac 休眠/离线时新任务排队；恢复后执行。前台仅对在途任务定时刷新，离开页面不持续轮询。返回调研列表保留原来的位置及提问草稿。手机私有目录缓存看过的报告和原文，离线可查看；更换服务地址时清理缓存。报告明确显示检索时间、覆盖正文数、未解析附件、去重和截断情况；原文修订变化后不会把当前正文冒充旧引句。

## 接口与边界

- 阅读凭据：`GET/POST /v1/research/tasks`、`GET /v1/research/tasks/{id}`。
- 发布凭据：`POST /v1/research/config`、`/v1/research/claim`、`/v1/research/tasks/{id}/complete`。
- 请求和结果都有体积上限，租约10分钟；过期租约不能覆盖新执行结果。
- AI眼镜等预置细分专题优先于大行业识别；未覆盖的专题可手动填写调研对象。自然语言识别歧义时要求填写明确对象/代码，而不是猜公司。检索采用确定性文本匹配，不是全库语义搜索；同义词遗漏、未归档正文和日期不明资料都可能造成覆盖不足。
- 追问继承对象和时间范围，重新检索；不把上一份 AI 结论作为事实证据。
- 不提供任意联网/执行工具；来源文本只当资料。引用格式校验不能证明每项陈述都被引句充分支持。
