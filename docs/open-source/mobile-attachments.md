# 原件清单与按需同步

此前移动同步只发现已有缓存，导致未在桌面打开过的图片及源文件没有手机入口。0.9 从当前归档版本读取完整 `source_attachments`，同步名称、类型、大小、状态与不包含来源签名的附件标识。缺失附件继续显示，不会当作没有附件。原件页面汇总清单及就绪数，搜索覆盖附件文件名。

手机请求 → 云端受限队列 → Mac 核对归档与当前版本 → 官方只读接口获取 → 本地缓存与内容哈希 → 私有云资源上传 → 清单状态更新 → 手机校验并下载。

图片打开文章后自动请求；PDF、音频和表格按按钮获取。Mac 每15秒处理最多三项；实际等待取决于队列、网络和源站，不承诺固定完成时间。手机等待时检查清单变化，超时保留重试入口。Mac 离线时请求留在云端。失败不会静默删去附件，单文件超过100MB需到原始来源获取。

PDF仍使用原生分页预览；音频不转写、表格不分析。原件下载后可交给手机已有播放器或表格应用打开。提供者只允许读取已校验的哈希缓存文件，拒绝写入和任意路径；未导出，使用单文件URI临时授权。

云端只持有阅读副本，不接收星球登录凭据、源站签名URL或模型密钥。读凭据只能为自己有权读取的当前清单附件排队；发布凭据用于Mac领取和完成任务。所有获取均经既有知识星球只读接口，无新增模型费用。

测试覆盖清单四种格式、已有缓存复用、任务鉴权/幂等/失败重试、附件归属和版本、域名与格式限制、音频与表格上传读取、文件名搜索及安卓文件URI只读隔离。旧APK可继续读取正文和已有资源，但完整清单入口需要升级。
