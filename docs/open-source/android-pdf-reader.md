# Android 原件 PDF 阅读器（0.12.0）

## 使用

在原件列表或研报附件中点击 PDF，下载完成后进入独立阅读页。已下载文件无需等待列表同步，可离线打开。

- 双指缩放、拖动查看，双击在适宽与放大之间切换。
- 顶部“适宽”“整页”重置显示方式。
- 底部上一页、下一页；拖动页码进度条快速定位。
- 点击中间页码输入目标页，超范围数字会提示纠正。
- 每份文件按内容哈希保存最后页码、缩放和视图中心；关闭后再打开可继续阅读，更新后的不同文件不混用旧位置。
- 返回保留原来的研报正文或文件列表，不再把原页面替换成PDF图片。
- “其他应用”提供系统PDF阅读应用选择入口，只授予该文件的临时只读访问。

## 性能与边界

使用 Android PdfRenderer 进行本地视觉渲染，不抽取文字、不做OCR、不调用模型。渲染放在单线程后台，每次仅保留一页显示位图；单页分辨率按屏幕与600万像素预算限制。旧位图替换后释放，关闭页面后释放资源。页面变更期间禁用重复翻页，失效回调不覆盖新页面。

原文件仍保存在应用私有缓存，阅读Activity不对外导出，传入参数只有合法文件哈希与显示名称，不含服务器凭据。损坏或不支持的PDF会提示使用其他应用，密码输入、全文搜索、文本复制、批注和连续长卷浏览尚未实现。

真机回归包含三页合成PDF的翻页、边界页码、缩放、显示方式、重新打开续读和返回原文视图。另用本机已有PDF进行实际操作验收。合成样例与测试状态在结束后清理。
