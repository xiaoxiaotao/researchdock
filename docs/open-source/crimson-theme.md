# 朱红主题（0.14）

参考 [同花顺财经](https://www.10jqka.com.cn/) 与 [东方财富](https://www.eastmoney.com/) 的财经产品布局与强调方式，采用朱红 `#B4232F` 作为统一品牌色。

- 安卓和 Mac 网页的导航、按钮、选中态、行业/公司标签及主标题统一使用红色层级。
- 白底正文搭配浅红 `#FFF0F1` 摘要区；正文保持深色，指标与链接保留蓝色，风险保留金色。主题红只表示品牌与交互强调，不把文字自动标为利好。
- 安卓系统弹窗、光标、勾选控件与 PDF 进度条同步为红色；应用图标使用红底书页和研究走势线条的原生矢量资源。
- CSS 使用内容更新版本号，浏览器刷新即可加载新样式。财报数据、归档原文、PDF 原件颜色与内容不作修改；配色变更不增加模型调用。

安卓最低版本仍为 Android 8.0，预览版支持覆盖更新并保留现有阅读凭据、收藏与阅读位置。
