# Android 0.10：原件浏览与离线正文

原件页从按帖子分组改为按文件呈现，名称、来源、格式、大小和就绪状态分层显示。PDF、音频、表格、图片可分别筛选；本机可用、云端就绪、待获取及失败状态独立筛选。每批最多60项，加载更多后保留滚动位置。补充归档文件也显示，但不会与原件清单中相同的就绪资源重复列出。

已就绪的PDF直接分页阅读；音频、表格可下载后授权手机已有应用打开。未就绪原件进入来源文章并定位到对应附件卡片，原文来源仍可核对。返回后保留文件类型、状态、加载数量与原列表偏移。

“云端就绪”表示云端持有原件，并不等于手机已经下载。“本机可用”只显示手机私有缓存中已有的原件；卸载应用或清理数据会移除这些缓存。未缓存正文和原件仍需要联网。

正文修订号相同且文档标识一致时，复用已缓存正文并应用最新目录元数据。云端强制同一修订的正文哈希不变，因此摘要、分类或附件状态更新无需重新下载相同正文。不同修订或不同文档绝不借用旧正文。异步取正文完成后会校验导航状态，避免用户已经切换页面却被带回旧文章。

Mac watch 发布器将源站原件获取放入最多两个后台任务，定期收集结果并发布。任务完成后保留到云端同步和回执均成功，才释放本地跟踪状态；失败保持可重试。获取原件不再占住常规资料发布循环，队列接口故障也不阻止正常资料同步。大文件上传仍会使用带宽，并非无限并行。一次性命令仍按同步流程处理。

新增测试覆盖：来源附件和补充归档去重；文件类型、文件名和本机状态过滤；同修订缓存合并与跨修订拒绝；对应附件定位、返回原列表及筛选保留；下载任务不阻塞轮询、并发上限及确认前保留结果。没有新增模型调用、手机权限或云端接口。
