# 研迹 Android 预览版

原生 Java / Android SDK，最低 Android 8.0，编译 SDK 35。通过 GitHub Actions 的 Android APK 工作流生成 debug 签名试用包。APK 不包含服务器地址或凭据。

功能：私有 HTTPS 连接、资料列表、行业 / 公司筛选、原文阅读、本机已读与收藏、已打开正文离线缓存、已同步图片缓存与 PDF 分页阅读。0.9 起完整同步原件清单，包含图片、PDF、音频和表格。已缓存原件直接复用；未缓存原件由手机发出获取请求，在线 Mac 使用本机授权下载后上传到私有云。图片在打开文章时自动请求；其他格式按需获取。PDF 内置分页阅读；音频和表格下载到手机私有缓存后，授权外部播放器或表格应用打开。单个原件上限100MB，超过限制仍显示清单和来源入口。

配置服务地址及单独的阅读凭据，不能填 DeepSeek Key。凭据使用 Android Keystore 加密；关闭系统备份。收藏与已读目前只在手机保存，未实现跨设备状态合并；前台每30秒检查云端变更，无变化时不重新拉取列表；手动同步可用。退出前台后停止轮询，后台自动同步与推送尚未实现。

维护者的预览包现使用私有固定签名，可覆盖更新；自行 Fork 构建时需配置自己的 ANDROID_PREVIEW_KEY（Base64 keystore）才能维持自己的升级身份。预览签名仍不同于应用商店正式发布策略。没有通过真机验证之前不能将 CI 构建成功等同于所有机型运行正常。

### 移动阅读排版

新版使用双列行业/公司入口，展示关联资料数量；信息流将来源、时间、标题、摘要和行业标签分层显示。阅读时收起搜索与底部导航，提供三档字号和独立摘要区。原文已有 Markdown 标题、加粗、列表和引用使用原生文字组件呈现，不调用模型判断重点。系统返回键可退出阅读。

设计参考：[Read You](https://github.com/ReadYouApp/ReadYou) 的阅读信息层级，以及 [Readest](https://github.com/readest/readest) 的排版与强调思路；未复制第三方代码。当前为轻量 Markdown 子集，支持常见表格，HTML 和数学公式仍按原文显示。

### 富文本阅读（0.3 预览）

- 一级、二级及小节标题使用分级字号与绿/蓝色层次。
- 已有摘要独立呈现；原文明确标出的“核心观点 / 核心结论 / 投资要点 / 研究要点”和“风险提示 / 风险因素”使用绿色、浅金色带边框区块。
- 支持加粗、行内代码、列表、引用、分隔线、可横向滑动的 Markdown 表格和 HTTP(S) 链接；不执行 HTML、脚本或自定义协议。
- 营收、净利润、现金流等指标名称使用蓝色强调，不推断涨跌或利好利空，不改写金额。
- 已归档图片按正文引用就地显示，其余归档配图在文末展示。未归档远程图片不自动向第三方发请求，保留原图链接。
- 不增加模型调用；复杂嵌套 Markdown、HTML 和数学公式尚不支持完整排版。

`ResearchTextTest` 提供 Android 真机仪器测试，验证表格、强调、图片回调、链接协议限制及原始金额保留。`visual_fixture=true` 可显示明确标注为样例的排版页面，不写入资料库。

### 研究工作台（0.4 预览）

首页提供资料、待阅读和收藏数量，以及全部 / 未读 / 续读 / 关注入口。来源与今天、近7天、近30天过滤按元数据在本机执行；日期以 Asia/Shanghai 的自然日计算，未标日期的资料只出现在全部时间。公司可在详情页关注，列表显示资料与未读数量，材料按发布日期分组。“未读”沿用本机是否打开过的记录，不表示已完成全文阅读。

阅读页支持原文章节目录、按当前修订保存滚动比例；列表可见未完成进度，提供继续阅读入口。新增修订从头开始。长原始 URL 显示为紧凑来源链接，但链接目标与归档原文不变。关注、位置和阅读状态仍只保存在本机，不跨设备同步；图片异步加载或字号变化可能使恢复位置与原先有少量偏差。

详细取舍与后续边界见 [产品调研](../docs/open-source/product-review-20261025.md)。

### 原件浏览与离线正文（0.10）

原件按文件展示，每批60项，支持类型、就绪状态和本机可用筛选。未就绪原件跳到对应附件卡片；已就绪PDF、音频和表格可直接打开。返回保留原列表和筛选。同一文档修订的正文缓存可搭配最新摘要与附件元数据使用；新修订须重新获取正文。详见[交互与缓存说明](../docs/open-source/mobile-original-browser.md)。

### 每日研究工作台（0.11）

首页提供今日收录、关注未读和继续阅读，关注公司材料优先显示。公司按关注和最近研究排序；关键观点与风险提示复用当前修订已有分析。顶部状态区分源站、Mac发布器、云端和手机检查，可点击查看详情。详见[完整说明](../docs/open-source/mobile-workspace.md)。

### PDF 原件阅读（0.12 预览）

独立阅读页支持双指缩放、拖动、双击放大、适宽/整页、页码进度条和指定页跳转。翻页保持缩放比例，重开保留页码及视图位置；返回原来的正文或文件列表。提供其他PDF应用打开入口。仅在本机视觉渲染，不抽取文字或调用模型。详见[PDF阅读说明](../docs/open-source/android-pdf-reader.md)。

## 0.13 手机 AI 调研

顶部“调研”输入公司或行业问题，阅读带出处报告并追问。执行在 Mac，离线排队；PDF/图片/音频不自动解析。详见 [部署及费用边界](../docs/open-source/mobile-research-assistant.md)。
