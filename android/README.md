# 研迹 Android 预览版

原生 Java / Android SDK，最低 Android 8.0，编译 SDK 35。通过 GitHub Actions 的 Android APK 工作流生成 debug 签名试用包。APK 不包含服务器地址或凭据。

功能：私有 HTTPS 连接、资料列表、行业 / 公司筛选、原文阅读、本机已读与收藏、已打开正文离线缓存、已同步图片缓存与 PDF 分页阅读。图片和 PDF 只同步 Mac 已缓存 / 导出的文件，未下载的星球原件不会凭空出现在云端。音频暂不在 APK 中播放。

配置服务地址及单独的阅读凭据，不能填 DeepSeek Key。凭据使用 Android Keystore 加密；关闭系统备份。收藏与已读目前只在手机保存，未实现跨设备状态合并；前台每30秒检查云端变更，无变化时不重新拉取列表；手动同步可用。退出前台后停止轮询，后台自动同步与推送尚未实现。

预览包不具备正式稳定签名升级策略，下一次 CI 构建的 debug 签名可能变化；正式分发前需配置维护者自持的发布签名。没有通过真机验证之前不能将 CI 构建成功等同于所有机型运行正常。

### 移动阅读排版

新版使用双列行业/公司入口，展示关联资料数量；信息流将来源、时间、标题、摘要和行业标签分层显示。阅读时收起搜索与底部导航，提供三档字号和独立摘要区。原文已有 Markdown 标题、加粗、列表和引用使用原生文字组件呈现，不调用模型判断重点。系统返回键可退出阅读。

设计参考：[Read You](https://github.com/ReadYouApp/ReadYou) 的阅读信息层级，以及 [Readest](https://github.com/readest/readest) 的排版与强调思路；未复制第三方代码。当前为轻量 Markdown 子集，复杂表格、HTML 和数学公式仍按原文显示。

### 富文本阅读（0.3 预览）

- 一级、二级及小节标题使用分级字号与绿/蓝色层次。
- 已有摘要独立呈现；原文明确标出的“核心观点 / 核心结论 / 投资要点 / 研究要点”和“风险提示 / 风险因素”使用绿色、浅金色带边框区块。
- 支持加粗、行内代码、列表、引用、分隔线、可横向滑动的 Markdown 表格和 HTTP(S) 链接；不执行 HTML、脚本或自定义协议。
- 营收、净利润、现金流等指标名称使用蓝色强调，不推断涨跌或利好利空，不改写金额。
- 已归档图片按正文引用就地显示，其余归档配图在文末展示。未归档远程图片不自动向第三方发请求，保留原图链接。
- 不增加模型调用；复杂嵌套 Markdown、HTML 和数学公式尚不支持完整排版。

`ResearchTextTest` 提供 Android 真机仪器测试，验证表格、强调、图片回调、链接协议限制及原始金额保留。`visual_fixture=true` 可显示明确标注为样例的排版页面，不写入资料库。
