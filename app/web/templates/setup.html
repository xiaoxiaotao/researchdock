开始使用 ResearchDock

先导入一份资料，再按需要接入信源和 AI。无需 API Key，也能阅读、搜索和导出。

1. 导入第一份资料

上传自己有权使用的 TXT、Markdown、JSONL 或 PDF。可以先使用源码 examples 目录中的合成示例，熟悉操作。

打开导入记录 查看资料库

2. 接入自己的信源（可选）

知识星球需要单独安装官方 CLI 并完成自己的授权。网页已登录不等于 CLI 已登录。先同步少量资料，确认正文与来源后再开启周期采集。

管理信源 同步证券名称与代码

3. 按需开启 AI

分类摘要和翻译会把相关文字发送给 DeepSeek，并可能产生费用。默认节省模式仅做必要的分类摘要；深度评分、事件观察和翻译由你按需运行。

AI 与每日更新设置
