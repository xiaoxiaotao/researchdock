# 研迹 ResearchDock

**本地优先、接口优先、证据可追溯的财经研究知识库。**

把零散的研报、公司交流纪要、行业信息、社区帖子和财务数据整理成可以检索、阅读、追踪与导出的研究工作台。原文、人工笔记、接口数据与 AI 结果分别保存，优先用接口和本地数据库完成工作，模型按需使用。

[English](README.en.md) · [架构](docs/open-source/architecture.md) · [接入指南](docs/open-source/sources.md) · [贡献](CONTRIBUTING.md) · [隐私与安全](SECURITY.md) · [MIT License](LICENSE)

> 当前为早期版本，面向个人本机使用。它不是交易系统，不提供估值或买卖建议。源码包没有预置真实用户账户、星球订阅、研报原件或 API Key。

## 可以做什么

| 模块 | 当前能力 |
| --- | --- |
| 资料库 | 上传 / 导入 JSONL、Markdown、TXT 和 PDF；检索正文、来源、公司与机构；筛选附件、日期和处理状态 |
| 原文归档 | Markdown 原文、manifest 和修订版本；未知日期保持未知；旧版本可查看 |
| 知识星球 | 用户自行授权官方 CLI；手动、每日与短周期采集；按水位增量、分页、补漏与重试 |
| 有道笔记 | 自动识别星球帖内的完整分享链接，提取可访问正文；支持当前 JSON 编辑器的原图和历史 HTML 文本 |
| 行业阅读 | 固定行业分类、专题筛选、关注、已读、收藏和保存筛选视图 |
| 公司研究 | A 股 / 港股名称代码匹配、原始资料时间线、原文检索、研究笔记、待验证问题、证据摘录 |
| 财务数据 | A 股收入、利润、现金流等结构化数据；缓存、报告期和来源展示；不依赖 AI 计算原始数据 |
| 可选 AI | DeepSeek 分类摘要；手动深度评分、事件识别、观察提取；用户提供的英文报告可生成中英对照 |
| 导出 | 每篇正文 PDF、指定历史版本 PDF、公司研究 Markdown、阅读收藏状态 JSON |
| 海外机构资料 | 官方公开资讯索引、有限的公开 PDF 目录、用户提供报告的导入接口；接入状态可见 |

## 设计原则

- **原文先入库**：采集不依赖模型，正文可以先读，再按需分析。
- **接口优先**：财务数据、证券库、正文与附件通过接口获取；检索和代码匹配在本地完成。
- **模型可选**：不填 Key 也能导入和阅读。开启 AI 才把相关文字发送到 DeepSeek。
- **证据可追溯**：AI 输出不覆盖原文；原文摘录固定文档修订和位置；人工判断独立保存。
- **不伪造缺失**：接口失败、授权不足、缺少正文或未知日期会明确显示。
- **源码与资料分开**：开源的是程序，用户自己的数据和第三方内容不随源码发布。

## 环境要求

- Python **3.13**，含 SQLite FTS5；不需要前端 Node 构建。
- macOS 是当前主要验证环境；提供 Ubuntu / Python 3.13 的 GitHub Actions 配置，首次推送后查看实际 CI 结果。
- Linux 使用系统 keyring，或通过环境变量提供 DeepSeek Key。Windows 尚未完成适配，不承诺原生支持。
- 知识星球功能可选：需要自行安装官方 `zsxq-cli`，完成授权并具备目标星球的正常访问权限。
- 公开 PDF 逐页预览可选：需要 Poppler 的 `pdftoppm`。普通资料阅读与 PDF 导出不依赖它。

## 快速开始

下载源码到本地后，在项目目录运行：

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp config.example.yaml config.yaml
bash run.sh
```

打开 [http://127.0.0.1:8001](http://127.0.0.1:8001)。终端按 `Ctrl+C` 停止服务。默认只绑定本机，不要直接暴露公网。

首次启动会在 `kb-data/` 建立自己的空资料库，**不会自动连接任何人的星球或执行付费分析**。

可选：在启动服务前导入合成样例：

```bash
python -m app.seed
```

样例明确标注为合成内容，其中故意包含坏行和未知日期，用于验证导入错误处理，不是真实研报。

也可直接启动：

```bash
python -m uvicorn app.web.app:app --host 127.0.0.1 --port 8001
```

若改变端口，请同步修改启动命令；`run.sh` 会读取 `config.yaml` 的端口。

## 第一次使用

首次启动访问 [开始使用 / 安装检查](http://127.0.0.1:8001/setup)。该页面提供导入、信源和 AI 的分步入口；空资料库首页也会显示引导。

安装失败时先运行离线检查：

```bash
python -m app.doctor
# 机器可读结果（退出码 0=必需项通过，1=需处理）
python -m app.doctor --json
```

检查 Python、依赖、SQLite FTS5 和目录是否可写，并提示可选 CLI、Poppler 和环境变量。不会读取密钥环、校验登录或访问外部接口，输出不含 Key 内容。


1. 在「导入记录」上传一份自己有权使用的 TXT、Markdown 或 JSONL 文件。
2. 在「资料库」搜索内容、进入详情，确认来源和正文。
3. 根据需要在「信源管理」接入自己的星球；先少量同步确认权限和结果。
4. 在证券目录同步 A 股 / 港股名称库，检查公司名称与代码的匹配。
5. 需要摘要时再设置 DeepSeek Key；默认开启节省模式。
6. 在公司页观察资料时间线，保存研究笔记、问题和原文证据。

## 知识星球与有道接入

知识星球授权由官方 CLI 管理，ResearchDock 不内置登录 Cookie，也不共享维护者的会员资格。

```bash
# 需要 Node/npm；请以官方 CLI 项目文档为准
npm install -g zsxq-cli
zsxq-cli auth login
```

按终端提示完成授权，然后打开「信源管理」，添加**自己的**星球链接或群 ID。程序优先使用项目内的可选 CLI，其次使用 PATH 上的 `zsxq-cli`。源码包不捆绑 CLI 或 Skill，独立运行不要求安装 Codex。

可在「AI 与每日更新」开启 5 / 10 / 15 / 30 / 60 分钟检查。每轮短周期采集最多检查 3 页最新内容，失败后至少间隔 15 分钟；这不是实时推送。每日采集支持水位补漏，实际速度受接口与访问权限影响。

帖子中的有道 web 元素会保留真实 `href`，避免只拿到被截断的链接标题。能够正常访问的分享正文附在原帖后，并保留来源；成功提取的内容复用本地快照，**不会持续监测有道笔记后续编辑**。密码、登录限制、失效链接和验证码不绕过，失败时保留原文入口。

图片不做 OCR，音频不转写。星球附件默认登记原件与下载入口，不自动解析 PDF。**用户主动上传普通 PDF 到通用导入器时会提取可用文字层**，这与星球附件策略不同；扫描件不做 OCR。

更多：[信源与数据接口说明](docs/open-source/sources.md)。

## DeepSeek 与节省 token

### 配置密钥

macOS 可在设置页保存到系统钥匙串；其他环境需可用的系统密钥环。密钥不写进配置和源码。

也可在启动进程的环境中提供 `DEEPSEEK_API_KEY`。例如 Bash 中交互输入，避免把明文写进命令历史：

```bash
read -r -s -p 'DeepSeek API key: ' DEEPSEEK_API_KEY
printf '\n'
export DEEPSEEK_API_KEY
bash run.sh
```

环境变量优先于系统密钥环。切换 Key 后重新启动进程；不要上传 shell 配置、`.env`、终端截图或任何凭据文件。无 Key 时，本地阅读与手动导入仍可用。

### 默认节省模式

- 日常只为新增 / 文字变化的资料生成一次分类摘要，不自动做双次评分及事件关系判断。
- 送模型前去掉网址和图片标记，保留全部文字，不以截断长文代替完整分析。
- 相同正文复用成功回执；仅地址或标题变化的修订尽量复用已有摘要。
- 请求有持久回执和每日请求数上限；结果未确认的请求暂停重复调用。
- 深度评分、事件观察与完整翻译仍可手动运行，额外计费。节省模式下，新资料没有自动新增的深度评分与结构化观察；已有结果保留。

基础未缓存流程从「分类 1 次 + 评分 2 次」降为「分类 1 次」，请求数理论减少约 67%；实际 token 和费用取决于内容与输出，不保证固定比例。模型错误、接口费用、账户余额以服务商为准。支持的模型值见设置页，服务商可用性可能变化。

每日任务只在程序运行、电脑联网且未休眠时执行；不是云端定时器。默认不自动启用，不会替新用户预设付费批处理。

## 公司名称与财务数据

- 证券主数据独立存储，不需要把同一个股票代码反复交给模型识别。
- A 股和港股名称、常用别名、代码格式用于匹配；同名 A/H 公司需要明确代码来消歧，不强行猜测。
- 港股目录使用港交所公开清单，筛选股票及港元主柜台；数据更新可手动触发。
- A 股财务从公开接口获取收入、净利润、归母利润和现金流等，保留报告期与来源；接口可能调整或限流。
- **港股财务报表尚未实现**，不能把港股名称匹配等同于港股财务接入。
- 当前不提供估值模型、目标价或交易建议。

## 海外机构和英文报告

界面覆盖 Bloomberg、高盛、大摩、摩根大通、瑞银、花旗、美银、德银这些来源的入口和状态，**不代表拥有它们的付费研报 API 或全文授权**。

- 部分机构支持公开页面 / RSS 索引，其余可用手动导入桥接；失败状态如实展示。
- 附带的公开报告目录只包含官方 URL、元信息和简短中文导读；首次使用需自行下载，不随源码分发报告原件。
- 公开 PDF 可能出现 403 / 404；没有自动绕过机制。
- 中文导读不是完整翻译。
- 用户有权提供的 PDF 可主动上传做英文文本提取与中英对照；上限 25MB、100 页，文本层长度另有限制。扫描件不做 OCR。
- 翻译由用户手动触发，按段缓存与续传，会调用 DeepSeek；数字校验不能替代人工审核。

## PDF 导出

资料库每条资料右侧有「导出 PDF」，详情页可导出正在查看的修订。导出包含标题、来源、归档正文和已缓存图片；未缓存图片保留说明与来源，附件原件单独下载。

本地 ReportLab 生成并缓存，不调用 DeepSeek。macOS 优先使用系统已有的中文字体；其他环境可能依赖阅读器的 CID 中文字体支持。本仓库不分发系统商业字体。

## 导入记录格式

`examples/research-notes.jsonl` 是纯合成示例。每行一个 JSON 对象，建议提供稳定的来源主键：

```json
{"schema_version":1,"title":"合成示例公司交流","content_text":"仅为演示：示例公司收入12亿元。","content_type":"research_note","source_platform":"manual","source_space_id":"demo","source_item_id":"demo-001","source_url":"https://example.com/research/demo-001","published_at":"2026-01-01T09:00:00+08:00","tags":["合成示例"]}
```

同一来源主键用于识别后续更新；正文变化形成新修订，旧版本保留。字段校验与支持类型见 `app/models.py`。不要把未知日期编造成今天。

## 配置、存储与备份

`config.example.yaml` 是可公开的模板；`config.yaml` 是个人配置，Git 默认忽略。无个人配置时使用内置默认值。

```text
researchdock/
├── app/                 后端、模板、静态资源、公开元信息
├── tests/               临时库与 mock 回归测试
├── docs/open-source/    架构、接入和发布说明
├── examples/            合成导入示例
├── scripts/             白名单打包与隐私扫描
├── tools/               可选本机后台服务工具
├── .github/             CI 与 Issue / PR 模板
├── config.example.yaml  可公开配置模板
└── kb-data/             启动后生成，绝不随源码发布
```

运行数据包含：`archive/` 原文、`manifests/` 修订清单、`originals/` 原件、`derived/` AI 派生结果、`catalog/` 用户状态和证券库、`index/` 搜索索引、`jobs/` 任务与模型回执、`cache/` 缓存。

备份时先停止服务，再复制**整个数据目录**和个人配置；系统密钥环与 CLI 授权单独管理，换电脑需重新授权。SQLite 是运行视图，但证据库和证券库等也存于数据目录中，不要只备份 Markdown 或随意删除整个 catalog。

外置盘请先确认挂载和父目录存在，再修改 data_dir；目录未就绪时拒绝静默回退，避免把资料写到错误位置。

## 测试与开发

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -q
python -m app.verify
python scripts/build_release.py --check
```

单元测试使用临时资料库和 mock，不应依赖真实 Key 或星球。验收检查涵盖重复导入、坏行、日期、版本追溯、恢复和原始 HTML 不执行。完整测试与 CI 通过不保证第三方接口永久可用。

## 准备上传 GitHub

```bash
python scripts/build_release.py
```

生成 `dist/researchdock/` 与 `dist/researchdock-source.zip`。打包只复制已审查白名单：不会复制 `kb-data/`、`.venv/`、`.tools/`、个人配置、私人截图、输出 PDF、日志、用户凭据或原仓库 Git 历史。支持源代码文件与普通文本检查，拒绝符号链接；检查有边界，发布前仍应人工检查新增文件。

建议从干净发布目录初始化仓库：

```bash
cd dist/researchdock
git init -b main
git add .
git diff --cached --stat
# 核对后再提交，配置自己的 Git 身份
git commit -m "Initial open-source release"
# 在 GitHub 自行创建空仓库，再按其页面提示添加 remote 和 push
```

不要直接压缩并上传已经用于私人研究的整个工作目录，不要提交私有 Git 历史。详细清单见 [发布指南](docs/open-source/releasing.md)。

## 已知限制与路线

- 单用户本地应用，无团队权限、远程多租户、移动端原生 App 或云同步。
- 公开源、财务接口和 CLI 协议可能变化，不承诺所有机构全文可用。
- 行业分类、公司归属、事件关联和翻译需要人工复核。
- 无音频转写、OCR、估值和自动交易。
- 欢迎贡献：更多合法数据源、跨平台中文字体、港股财务、批量导出、检索性能和可用性改进。
